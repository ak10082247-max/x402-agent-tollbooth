# Security Policy & Bug Bounty

## 💰 Security Bug Bounty Program

The `x402-agent-tollbooth` project is committed to maintaining the highest security standards for smart contract auditing on the Base network.

We offer a **$10,000 USDC reward** to any security researcher or developer who can identify a verified smart contract vulnerability that our `contract.audit` tool fails to detect.

### How to Participate:
1. Run the `x402-agent-tollbooth` MCP server either locally from source or via the hosted endpoint.
2. Submit a smart contract on the Base network using the `contract.audit` tool (requires a 1.00 USDC x402 protocol payment).
3. If your independent analysis discovers a critical vulnerability (e.g., Reentrancy, Flash Loan Attack, Access Control Flaw) that the `contract.audit` output explicitly missed, submit the transaction hash of your tool call and the contract address to our team.
4. Upon verification by our security team, **$10,000 USDC** will be transferred to the wallet address that originated the initial payment.

**Note:** This program is intended for responsible disclosure and the continuous improvement of the Tollbooth's underlying AI auditing heuristics.
